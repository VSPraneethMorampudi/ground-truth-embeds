The cinematic opening uses self-hosted Latin WOFF2 subsets from Google Fonts:

- Fraunces, by Undercase Type: https://github.com/undercasetype/Fraunces
- Instrument Sans, by Instrument: https://github.com/Instrument/instrument-sans

Both are licensed under the SIL Open Font License 1.1. Their license files are
included here. Fonts are served locally; the existing Anek Devanagari and
Geist Mono families remain available for Hindi and telemetry respectively.
